# Extração de dados - Relatórios de Desempenho
## O que é a solução?
A extração de dados financeiros de instituições financeiras é uma das etapas mais importantes para entender estratégias de concessão de crédito, exposição no mercado, saúde financeira e outros dados estratégicos utilizados por outras empresas, investidores e outros bancos. Já existem soluções que consolidam dados dessas instituições, como o IF ata, disponibilizado pelo BACEN, porém, o site não disponibiliza todos os dados, além de que outros dados mais específicos são normaalmente encontrados em PDFs e em Powerpoints. 

## O Contexto
A criação da resolução 4966 pelo BACEN em 2025 tornou o cálculo por estágio de ativos problemáticos obrigatória para bancos e fintechs. Os dados relacionados a exposição bruta e perda esperada são de extrema relevância para entender a disposição de risco de Crédito, a posição de uma instituição e estratégias de contenção de clientes. Dados como esses permitem maior granularidade dos dados para projetos maiores de gestão estratégica bancária.

## Como utilizar?
Nesta versão do projeto, os dados ainda são separados por notebook. É esperado que seja unificado e aplicável para qualquer instituição financeira ( com o "Extrator - Multibanco" ), e que sirva como banco de dados para agentes de IA. No geral, coloque o 
arquivo PDF desejado ( neste caso, apenas demonstrações financeiras funcionam ), e mude alguns parâmetros, como data e tipo de extração, de acordo com o Extrator. 

*O projeto ainda é um MVP*
